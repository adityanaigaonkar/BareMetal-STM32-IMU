# BareMetal-STM32-IMU

STM32 bare-metal IMU project using CMSIS and the MPU6050 sensor.

## Features
- MPU6050 interfacing via I2C
- Accelerometer data acquisition
- Gyroscope data acquisition
- Roll and pitch estimation
- UART data transmission
- Register-level STM32 programming

## Hardware
- STM32 Microcontroller
- MPU6050 IMU
- USB-UART Adapter

## Future Improvements
- Complementary Filter
- Kalman Filter
- ESP32 Telemetry
- Yaw Estimation
